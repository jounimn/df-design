# Research log: Faísca (selling-positioning)

Access date for every entry: 2026-10-29. Behance was not used: it answers 403 to scripted access, so the base was built from BP&O (bpando.org) case pages, which render for a headless browser. Each case was opened in Playwright and three viewport captures were taken (top, one third, two thirds) and read as a contact sheet. BP&O shows a membership wall after three articles per browser session; the first run hit it on cases 4 to 39, so those were recaptured with a fresh browser context per page and the recaptures were read.
