How it works

One trace. Every hop. Nothing guessed.

  1. 01

    Instrument once

    Add @tracewell/sdk and call trace.init(). HTTP, gRPC, queues and SQL are wrapped for you.

  2. 02

    Propagate context

    W3C traceparent headers ride along every hop, so each service adds its span to the same trace.

  3. 03

    Read the waterfall

    Every span is drawn where its time went. Slow spans are flagged against their own p99, not a global threshold.
